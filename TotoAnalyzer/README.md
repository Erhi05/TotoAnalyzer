# Тото Анализатор

Конзолно .NET 8 приложение, което изтегля реални исторически данни от официалния сайт на **Спорт Тото** (6 от 49) и предоставя интерактивен статистически анализ с ASCII визуализации директно в конзолата.

## Функционалности

| Модул | Описание |
|-------|----------|
| **DataLoader** | Изтегля TXT и DOCX файлове с тиражи от `info.toto.bg` чрез `HttpClient` |
| **Statistics** | LINQ анализ – топ числа, горещи двойки, разпределение по десетици |
| **Visualizer** | ASCII хоризонтална лентова диаграма + цветна топлинна карта 7×7 |
| **Menu** | Интерактивно конзолно меню с избор на период и валидация на входа |

## Структура на проекта

```
TotoAnalyzer/
├── Models/
│   └── Draw.cs          # Модел на един тираж
├── DataLoader.cs         # Модул 1 – изтегляне & парсване (TXT + DOCX)
├── Statistics.cs         # Модул 2 – LINQ анализ
├── Visualizer.cs         # Модул 3 – ASCII графики
├── Program.cs            # Модул 4 – интерактивно меню
└── TotoAnalyzer.csproj
```

## Изисквания

- .NET 8 SDK или по-нова версия
- Интернет връзка (за изтегляне на данните)

## Стартиране

```bash
cd TotoAnalyzer
dotnet run
```

### Топлинна карта 7×7

Числата са оцветени според честотата им:
- 🔴 **Горещи** (топ 30%) – `ConsoleColor.Red`
- 🟡 **Неутрални** (средни 40%) – `ConsoleColor.Yellow`
- 🔵 **Студени** (долни 30%) – `ConsoleColor.Cyan`

## Технически детайли

- Платформа: .NET 8, Console Application
- Забранени пакети: без HtmlAgilityPack или HTTP-парсване
- Разрешени NuGet пакети: само `DocumentFormat.OpenXml` (за DOCX файлове)
- Всички HTTP заявки – само с вградения `System.Net.Http.HttpClient`
- Данните са публично достъпни на: https://info.toto.bg/statistika/6x49
